# Period-medicine reference per language (LOC-0041)

Translators use the **Galenic/early-modern** term in the left columns and never the modern clinical
terms in the *Banned* column (unless a line is deliberately anachronistic — there are none in Ch I–II).
Reviewers flag banned terms as register errors (LQA checklist).
