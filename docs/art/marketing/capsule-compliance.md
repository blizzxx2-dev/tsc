# Steam capsule compliance checklist (ART-0321)

Tick every box for **each** base capsule before it is uploaded (header, small, main, vertical,
library capsule, library hero, library logo, page background, community icon), then sign at the
bottom. Keep the signed copy with the upload record. This is Valve's graphical-asset rule for
base capsules, applied to our art. Event and sale artwork follows its own event rules.
